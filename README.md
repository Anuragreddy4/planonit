# Planonit - AI-Powered Study Planner 📚

Planonit is an intelligent study planning application that helps students create personalized study plans and analyze previous year question papers using AI.

## Features

- **AI-Powered Study Plan Generation**: Enter your syllabus and get a comprehensive, personalized study plan generated by ChatGPT
- **PDF Analysis**: Upload previous year question papers (PDF format) to get insights on important topics, frequently asked questions, and study recommendations
- **Simple and Intuitive UI**: Clean, responsive interface that works on desktop and mobile devices
- **Real-time Analysis**: Get instant feedback and analysis powered by OpenAI's ChatGPT

## Technology Stack

### Frontend
- HTML5
- CSS3 (with modern gradients and animations)
- Vanilla JavaScript (ES6+)

### Backend
- Node.js
- Express.js
- OpenAI API (ChatGPT)
- pdf-parse (for PDF text extraction)
- Multer (for file uploads)

## Prerequisites

Before running this application, make sure you have:

1. **Node.js** (version 14 or higher) installed
2. **npm** (comes with Node.js)
3. **OpenAI API Key** - Get one from [OpenAI Platform](https://platform.openai.com/)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Anuragreddy4/planonit.git
cd planonit
```

2. Install dependencies:
```bash
npm install
```

3. Create a `.env` file in the root directory:
```bash
cp .env.example .env
```

4. Open the `.env` file and add your OpenAI API key:
```
OPENAI_API_KEY=your_actual_api_key_here
PORT=3000
```

## Running the Application

1. Start the server:
```bash
npm start
```

2. Open your browser and navigate to:
```
http://localhost:3000
```

3. You should see the Planonit homepage with two main features:
   - Study Plan Generator
   - PDF Analyzer

## Usage

### Generating a Study Plan

1. Enter your syllabus in the text area (e.g., "Calculus, Linear Algebra, Probability, Statistics")
2. Click "Generate Study Plan"
3. Wait a few seconds for the AI to generate your personalized study plan
4. Review the plan which includes:
   - Topic breakdown
   - Time allocation suggestions
   - Study tips and strategies
   - Recommended study order

### Analyzing Previous Year Papers

1. Click "Choose File" and select a PDF of previous year question papers
2. Click "Analyze PDF"
3. The system will:
   - Extract text from the PDF
   - Analyze the content using ChatGPT
   - Provide insights on:
     - Key topics covered
     - Frequently asked questions
     - Important concepts to focus on
     - Pattern analysis and recommendations

## API Endpoints

### POST `/api/generate-plan`
Generate a study plan based on syllabus.

**Request Body:**
```json
{
  "syllabus": "Your syllabus text here"
}
```

**Response:**
```json
{
  "studyPlan": "Generated study plan text..."
}
```

### POST `/api/analyze-pdf`
Analyze a PDF file of previous year question papers.

**Request:** Multipart form data with PDF file

**Response:**
```json
{
  "analysis": "AI-generated analysis...",
  "extractedText": "Preview of extracted text..."
}
```

### GET `/api/health`
Check server health status.

**Response:**
```json
{
  "status": "ok",
  "message": "Planonit API is running"
}
```

## Configuration

You can customize the following in the `.env` file:

- `OPENAI_API_KEY`: Your OpenAI API key (required)
- `PORT`: Server port (default: 3000)

## Security Notes

- Never commit your `.env` file or expose your API key
- The application automatically deletes uploaded PDFs after processing
- File uploads are restricted to PDF files only

## Troubleshooting

### "Failed to generate study plan" error
- Check that your OpenAI API key is correctly set in `.env`
- Verify you have internet connectivity
- Ensure you have available credits in your OpenAI account

### "Could not extract text from PDF" error
- Make sure the PDF contains actual text (not just images)
- Try a different PDF file
- Ensure the PDF is not corrupted

### Server won't start
- Check that port 3000 is not already in use
- Verify all dependencies are installed (`npm install`)
- Check for any syntax errors in the console
